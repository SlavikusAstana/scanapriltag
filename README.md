# AprilTag Scanner Pro (C#)



Сканер AprilTag для Windows — без Python, без установки .NET на целевом ПК.



## Быстрый старт



1. **`build.bat`** — собрать (один раз, или после изменений)

2. **`dist\AprilTagScanner\AprilTagScanner.exe`** — двойной клик



`run.bat` — необязательный ярлык на тот же exe.



Для переноса на другой ПК: скачайте **`AprilTagScanner-win-x64.zip`** из раздела **Releases** на GitHub или соберите локально (`build.bat`).



## Требования для сборки



- [.NET 9 SDK](https://dotnet.microsoft.com/download)

- Windows 10/11



## Антивирусы



Сборка **не упаковывает** exe в один self-extract-файл (такие часто дают ложные срабатывания).  

Вместо этого — обычная папка с exe и DLL рядом, без распаковки во `%TEMP%`.



100% гарантии нет: неподписанные exe могут всё равно проверять SmartScreen.  

Надёжнее всего — **цифровая подпись** (Code Signing) при публикации для широкой аудитории.



## Возможности



- Live-сканирование, несколько тегов на листе

- Автоопределение семейства до «Старт»

- Семейства: **36h11, 25h9, 16h5, 36h10**

- Режим нескольких семейств (36h11+25h9+16h5)

- Профили скорости: Быстро / Баланс / Точно

- Умные повторы (без ложных от мерцания камеры)

- Подсветка повторов + звук

- Экспорт TXT / CSV / JSON

- Детекция в фоновом потоке (UI не зависает)



## Управление



| Действие | Клавиша |

|----------|---------|

| Сохранить | **Ctrl+S** |

| Сброс | **Ctrl+R** |
